## 1. 一句话定位

**你的第二海马体。** 把每天刷到的碎片化阅读自动整理、归档、并合成可听播客，解决"收藏不看 + 找不回来"两大问题。

不与 NotebookLM 竞争，不做公众号矩阵；做一个自己每天用、越用越合自己口味的私人知识收件箱。

## 2. 真实痛点（用户自述）

| # | 痛点 | 频率 |
|---|---|---|
| 1 | AI 内容迭代飞快，看到好文章想留着以后整理，结果攒了一大堆 | 每天 |
| 2 | 想查上个月看过的某篇文章，翻遍收藏夹找不到 | 每周 |
| 3 | AI 圈每天 50 条更新，攒着想找时间细看，越攒越多 | 每天 |

底层共识：**不是记性问题，是信息流量大了。** 大脑该腾出来思考和创造，"记忆 + 检索"这件事可以外包。

## 3. 核心机制

```
看到有用的 → 扔进去 → 后台自动整理 → 通勤听 / 随时查
              ↓             ↓                ↓
           零摩擦         不用管          多档详细程度
```

1. **扔进去**：截图 / 文字 / 链接（小红书 + 公众号），任意一种。不需要分类、不需要打标签。
2. **后台整理**：OCR、概念抽取、自动归档分类。用户不用做事。
3. **生成播客**：自动产出 3 分钟速听版 + 章节摘要 + 详版，三档随选。
4. **个性化**：信息密度、播客定位、关注领域三个轴用户自己调，越用越合口味。

## 4. 用户旅程

| 场景 | 触发 | 用户期望 |
|---|---|---|
| **看到了** | 早上刷到一篇值得看的 AI 文章 | 截图扔进去，2 秒内能闭掉小程序去做别的 |
| **听一下** | 通勤戴上耳机 | 今天的速听版已经准备好，3 分钟 / 章节 / 详版三选 |
| **跳过已知** | 听到自己已经熟的部分 | 跳过这章，进入下一节 |
| **查回来** | 想起上个月某篇关于 X 的文章 | 在档案里搜得到，不用翻收藏夹 |
| **调口味** | 主播听不下去 / 偏好领域变了 | 在「我的」里改信息密度、对谈偏好、关注领域 |

## 5. 功能需求

### 5.1 输入（新建页 / NEW）

| 输入方式 | 来源 | 必需 |
|---|---|---|
| 文字 / TXT | 直接粘贴 | ✅ MVP |
| 图片 / IMG | 截图（小红书 / 公众号 / 任意来源） | ✅ MVP |
| 链接 / URL | 小红书图文笔记 + 公众号图文文章 | ✅ MVP |

- 视频暂不支持，明确告知用户
- 提交后 fire-and-forget，1 秒内返回任务 ID，用户可立即关闭小程序
- 处理状态：pending → processing → done / failed

### 5.2 处理管线（云端，用户无感）

1. **视觉 OCR**（图片输入时）— `qwen3-vl-plus`
2. **概念抽取** — 5-10 个候选概念
3. **三路扩展**（并行）— 背景 / 关联 / 批判视角
4. **综合学习资料**
5. **对话稿生成** — 双主播，按用户偏好的对谈风格
6. **TTS 合成** — 双人对话播客，原生双人音色
7. **归档** — 写入 tasks 集合，支持后续检索

详细模型与切换矩阵见 [MODELS.md](MODELS.md)。

### 5.3 播客页（今日速读 / TODAY）

| 元素 | 说明 |
|---|---|
| 主播身份 | 两位拟人化主播（如「小诺 · 阿明」），昵称跟随用户配置 |
| 播放时长 badge | 3 MIN. / FULL 等 |
| 波形播放器 | -15s / pause / +30s |
| 核心观点章节 | 顺序排列，编号 01/02/03... 支持点击跳章 |
| 锁屏播放 | wx 后台音频管理器，离开小程序仍可听 |

详细程度三档（用户可在播放页切换）：
- **3 分钟速听**：TLDR 版，通勤地铁速通
- **章节摘要**：每章 1-2 分钟，跳过已知段落
- **详版**：完整双人对话，想深扒就听全的

### 5.4 档案页（ARCHIVE）

- 时间序列列出所有已生成的播客
- 支持按概念、领域、来源平台过滤
- 全文检索（标题 + 概念 + 章节）

### 5.5 我的（ME / 约稿单）

> "填完这份单子，听到的播客会更像写给你的。"

| 配置项 | 类型 | 选项示例 |
|---|---|---|
| **身份** | 单选 / 自填 | 设计师 / 工程师 / 学生 / 创业者 / 自填 |
| **信息密度** | 单选（滑块） | 轻 / 中 / 密 |
| **播客定位 / 对谈偏好** | 多选 | 严肃学术 / 轻松日常 / 反共识犀利 / 工具方法论 / 故事化讲述 / 速度快 / 慢节奏 |
| **关注领域** | 多选 + 自定义 | AI / 商业 / 心理学 / 设计 / 编程 / 哲学 / 行为经济学 / 历史 / 科学 / 文学 / + 自定义 |

配置变更不重处理已生成的播客，从下一次新建开始生效。

## 6. 非功能需求

| 维度 | 要求 |
|---|---|
| **首次提交响应** | < 1 秒（fire-and-forget） |
| **端到端管线** | ≤ 5 分钟（图片输入），≤ 3 分钟（文字输入） |
| **可靠性** | 单次任务失败重试 1 次；失败可见原因 |
| **存储** | 单次任务 < 10MB（含音频）；7 天内不主动清理 |
| **安全** | 用户只能读自己的任务；写操作只能由云函数发起 |
| **隐私** | 不出云函数；不分析用户内容；不外发 |

## 7. 视觉语言

**STUDY MAG · 学習マガジン**（杂志风），与产品 UI 一致：

- 暖米色底（#F4EFE6） + 极淡点纹
- 黑色厚重 sans-serif masthead
- 红色 vermillion（#DD3018） badge 做强调
- 黄色 mustard（#F5C842）横笔做关键词高亮
- 双语小标签：「中文 / ENGLISH」
- 片假名副标做节奏：学習マガジン / INPUT MODE / LEDE / TODAY / ME

详见对外推文图卡：[image-cards/xueban-mini-program/](../image-cards/xueban-mini-program/)

## 8. 范围外（v3 不做）

- 视频内容输入（B/YouTube 视频转播客）
- 多语言播客（仅中文双主播）
- 分享 / 社交 / 评论
- 公开发布到小程序商店
- 多账号 / 团队协作
- 实时播客（边读边听）
- 付费 / 订阅
- 网页端

## 9. 成功指标（自用版本）

不用 DAU / 留存，用「这玩意儿到底有没有把我从收藏夹里救出来」：

| 指标 | 目标 |
|---|---|
| 每周扔进去的内容 | ≥ 10 条 |
| 每周实际听完的播客 | ≥ 5 条 |
| 找回旧文章的成功率 | ≥ 80% |
| 主播口味满意度 | "不想跳过 / 不会嫌烦" |
| 听播客时是否走神 | 听到能反复回来 |

不达标 = 产品不够好，回去改。

## 10. 已知问题 / 未决

- 双人对话 TTS 偶有韵律不自然（待选优 TTS provider）
- "详版" 时长易 > 15 分钟，需要切片策略
- 链接输入对小红书登录态依赖（图文笔记 OK，视频笔记不行）
- 个性化配置如何低成本验证有效（暂无 A/B，依赖个人直觉）
