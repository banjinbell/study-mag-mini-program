# Content Analysis · 学伴小程序介绍（修订版）

## 真实定位
**你的第二海马体**——专门负责记忆的外挂大脑器官。
你的脑子负责 think，学伴负责 remember & retrieve。

> 海马体（hippocampus）是大脑中负责把短期记忆固化成长期记忆、并支撑检索的脑区。
> "第二海马体" = 外挂的记忆 + 检索器官，专治"看了就忘 / 想找找不到"。

视觉锚点：拟人化的**小海马**（macaron 蓝/薄荷色），整个系列的"吉祥物"，贯穿 6 张图。

## 真实痛点（用户原话）
1. **AI 内容迭代飞快**，看到好文章想留着以后整理 → 攒了一大堆没动
2. **想查之前看过的文章**，发现找起来非常麻烦
3. 收藏 ≠ 学到，但又舍不得不收藏

## 真实解法
1. **碎片知识自动收集**：看到有用内容就先扔进去，不用马上看
2. **后台自动生成播客**：有空再听，TLDR 思路
3. **3min 凝练播客** + 重点摘要 + 章节总结 + **不同详细程度**（跳过已知 / 详读不懂的）
4. **个性化适配**：每个人偏好的播客风格 + 关注的领域

## 核心价值主张
- 「攒着」也有用，因为攒进来的会被自动整理
- 信息密度可调，3min 速通 or 深度听完都行
- 越用越懂你（风格/领域个性化）

## 受众画像
- AI / 科技 / 创业领域的从业者和学习者
- 每天刷 X、Reddit、公众号、Newsletter 的信息密集型用户
- 通勤族（地铁/开车/走路）
- 有"知识焦虑"的人，收藏夹永远 99+

## 视觉机会
- 收藏夹 / 浮窗满屏的混乱感
- 「扔进去就行」的轻松感
- 播客波形 + 3min 计时
- 分层播客的滑块/档位
- 个性化齿轮 / 喜好标签

## 滑动节奏（6 张）
1. **封面**：钩子——"我做了个小程序治我的 AI 知识焦虑"（sparse）
2. **痛点**：3 条共鸣痛点（balanced）
3. **解法 1 · 收集**：看到就扔进去，后台帮你整理（balanced）
4. **解法 2 · 播客**：3min TLDR + 详版 + 章节，跳过已知（flow）
5. **解法 3 · 个性化**：风格 + 领域适配，越用越懂你（balanced）
6. **CTA**：微信搜「学伴」即可使用（sparse）

## 选定方案
- **策略**：合并 A（故事种草）+ B（信息密度），偏 A
- **风格**：sketch-notes 手绘 macaron（小红书友好 + 知识感）
- **布局**：封面/结尾 sparse，内页 balanced + 一张 flow
- **配色**：macaron（暖奶油 + 蓝紫薄荷桃 + 珊瑚红强调）
- **图数**：6 张
