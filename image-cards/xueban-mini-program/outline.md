# 学伴小程序 · 小红书 6 图大纲（杂志风版）

> 沿用产品本身的视觉语言：**STUDY MAG · 学習マガジン** 杂志风。
> 视觉锚：黑色厚 masthead、红色 vermillion badge、黄色 mustard 高亮、点纹奶米底、片假名副标。
> 中间 3 张就是产品截图，前后 3 张做匹配的杂志页。

## 杂志风格基底（所有生成卡通用）

- **底色**：暖米色 #F4EFE6，叠极淡的灰色点阵网格（很细，像新闻纸）
- **主色字**：极黑 #1A1A1A，标题极粗 sans-serif（思源黑体 Heavy / 方正兰亭粗黑感）
- **强调红**：vermillion #DD3018，用于小矩形 badge、点缀线、Tab 图标
- **高亮黄**：mustard #F5C842，仅用于中文关键词的横向高亮笔
- **片假名副标**：日文サブタイトル，黑体或细黑，永远比中文小
- **双语小标签**：「中文 / ENGLISH」格式，如「投稿方式 / INPUT MODE」「导读 / LEDE」
- **粗黑横线**：masthead 下面一道粗黑横线，区分头部
- **黑色按钮**：低圆角、内嵌 `▎ 文字 ▎` 字样
- **禁止**：渐变、阴影、立体、卡通脸、emoji、wobble、撒花

## 杂志元素库

- 顶部小 badge：红底白字 `STUDY MAG · 学習マガジン`
- 大写英文期刊号：`STUDY MAG · 2026-06-02`
- Lede 块：`导读 / LEDE` + 灰色文字
- 章节标号：黑色方块 `01` `02` `03`，配中文内文
- 下划线高亮：黄色 mustard 横笔，仅压在中文关键词下
- 页脚短句：`BY AI · 仅供学习参考 · FOR STUDY ONLY` 风格
